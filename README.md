# Dayflow - Human Resource Management System

Dayflow is a web-based Human Resource Management System designed to handle the regular HR activities of an organization digitally.

The system provides separate access for HR officers and employees. HR can manage employee details, attendance, leave requests and payroll-related information, while employees can manage their profile, mark attendance and apply for leave.

## Features

- User login and signup
- HR and Employee roles
- Employee management
- Employee profile management
- Attendance check-in and check-out
- Attendance history
- Leave and time-off requests
- Leave approval and rejection by HR
- Payroll management
- Employee notifications
- HR dashboard
- Employee dashboard
- Basic HR reports
- Employee profile and company logo uploads

## User Roles

### HR Officer

HR officers can:

- Manage employee records
- View employee profiles
- Monitor attendance
- View leave requests
- Approve or reject leave requests
- Manage payroll information
- View HR reports

### Employee

Employees can:

- Log in to their account
- View their profile
- Update permitted profile information
- Check in and check out
- View attendance records
- Apply for leave
- View leave request status
- View payroll information
- Receive notifications

## Database

MySQL is used as the database for this project.

It stores the information required for the HRMS, including employee details, login information, attendance, leave requests, payroll and other HR-related records.
